# 运行命令指南

## 1. 环境安装

```bash
# 创建虚拟环境 (推荐)
conda create -n dexvlg python=3.10
conda activate dexvlg

# 安装 PyTorch (根据 CUDA 版本选择)
# CUDA 11.8
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
# CUDA 12.1
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121

# 安装其他依赖
pip install -r requirements.txt
```

## 3. 数据准备

确保数据文件和网格文件路径正确：

```bash
# 数据文件结构
data/
├── train.json    # 训练集
├── val.json      # 验证集
└── test.json     # 测试集

# 网格文件路径 (在 configs/default.yaml 中配置)
# 默认: /mnt/afs/L202500241/Dataset/MeshProcess/assets/object/oakink_obj/processed_data/{obj_id}/mesh/simplified.obj
```

如需修改数据路径，编辑 `configs/default.yaml` 中的 `data` 部分：

```yaml
data:
  train_data: "your/path/to/train.json"
  val_data: "your/path/to/val.json"
  test_data: "your/path/to/test.json"
  mesh_root: "your/path/to/mesh/root"
```

## 4. 训练

### Stage 1: 全模型端到端训练

```bash
# 单卡训练
python train.py --config configs/default.yaml --stage 1

# 指定输出目录
python train.py --config configs/default.yaml --stage 1 --output_dir outputs/exp01

# 从断点恢复
python train.py --config configs/default.yaml --stage 1 --resume outputs/checkpoints/stage1/epoch_0020.pt
```

### Stage 2: 冻结骨干网络，微调 Flow-Matching Head

```bash
# 使用 Stage 1 最佳 checkpoint 开始 Stage 2
python train.py --config configs/default.yaml --stage 2 --resume outputs/checkpoints/stage1/best.pt
```

### 多卡分布式训练 (DDP)

```bash
# 2 卡
torchrun --nproc_per_node=2 train.py --config configs/default.yaml --stage 1

# 4 卡
torchrun --nproc_per_node=4 train.py --config configs/default.yaml --stage 1

# 多机多卡
torchrun --nnodes=2 --nproc_per_node=4 --node_rank=0 --master_addr=192.168.1.1 --master_port=29500 \
    train.py --config configs/default.yaml --stage 1
```

### 训练超参数修改

编辑 `configs/default.yaml`：

```yaml
training:
  stage1:
    epochs: 50        # 训练轮数
    batch_size: 32    # 批大小 (根据显存调整)
    lr: 1.0e-4        # 学习率
    warmup_steps: 1000 # 预热步数
    grad_clip: 1.0    # 梯度裁剪
  fp16: true           # 混合精度 (推荐开启)
```

## 5. 评估

```bash
# 基本评估
python test.py --config configs/default.yaml --checkpoint outputs/checkpoints/stage1/best.pt

# 自定义参数
python test.py \
    --config configs/default.yaml \
    --checkpoint outputs/checkpoints/stage2/best.pt \
    --num_steps 50 \
    --batch_size 16 \
    --output_dir results/exp01

# 保存逐样本预测结果
python test.py \
    --config configs/default.yaml \
    --checkpoint outputs/checkpoints/stage2/best.pt \
    --save_predictions \
    --output_dir results/exp01
```

评估结果保存在 `--output_dir` 指定的目录下：
- `metrics.json`: 聚合指标
- `predictions.json`: 逐样本预测 (需 `--save_predictions`)

### 评估指标说明

| 指标 | 含义 | 单位 |
|------|------|------|
| `left/trans_err_cm` | 左手平移误差 | 厘米 |
| `right/trans_err_cm` | 右手平移误差 | 厘米 |
| `left/rot_err_deg` | 左手旋转误差 | 度 |
| `right/rot_err_deg` | 右手旋转误差 | 度 |
| `left/joint_err_deg` | 左手关节角误差 | 度 |
| `right/joint_err_deg` | 右手关节角误差 | 度 |
| `left/trans_success_2cm` | 左手平移 < 2cm 成功率 | 比例 |
| `right/rot_success_15deg` | 右手旋转 < 15° 成功率 | 比例 |

## 6. 单样本推理

```bash
# 基本推理
python inference.py \
    --config configs/default.yaml \
    --checkpoint outputs/checkpoints/stage2/best.pt \
    --mesh_path /path/to/object/mesh.obj \
    --instruction "用双手抓住杯子的把手"

# 调整采样步数和点云数量
python inference.py \
    --config configs/default.yaml \
    --checkpoint outputs/checkpoints/stage2/best.pt \
    --mesh_path /path/to/mesh.obj \
    --instruction "Pick up the mug by the handle" \
    --num_steps 100 \
    --n_points 10000 \
    --scale 0.1

# 可视化 (需要 Open3D 和显示器)
python inference.py \
    --config configs/default.yaml \
    --checkpoint outputs/checkpoints/stage2/best.pt \
    --mesh_path /path/to/mesh.obj \
    --instruction "Grasp the bottle" \
    --visualize

# 保存可视化图片 (无需显示器)
python inference.py \
    --config configs/default.yaml \
    --checkpoint outputs/checkpoints/stage2/best.pt \
    --mesh_path /path/to/mesh.obj \
    --instruction "Grasp the bottle" \
    --output results/grasp_vis.png
```

## 8. 常见问题

### 显存不足 (OOM)

```yaml
# 减小 batch_size
training:
  stage1:
    batch_size: 16  # 从 32 减到 16

# 或减少点云采样数
data:
  n_points: 4096    # 从 10000 减到 4096
```

### BERT 权重下载失败

模型会自动 fallback 到随机初始化的 BERT。如需使用预训练权重：

```bash
# 手动下载
python -c "from transformers import BertModel, BertTokenizer; BertTokenizer.from_pretrained('bert-base-uncased'); BertModel.from_pretrained('bert-base-uncased')"
```

### 分布式训练端口冲突

```bash
# 指定其他端口
torchrun --master_port=29501 --nproc_per_node=2 train.py --config configs/default.yaml --stage 1
```
